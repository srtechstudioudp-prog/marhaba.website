How we write these guides

Each guide is general trade knowledge, written in plain language and checked for practical use. We do not publish prices, delivery promises or claims about specific machines in a guide. Where a figure appears, it is labelled typical or illustrative.

If a guide leaves your question open, send it to us. Real buyer questions decide which guide we write next, so your question may become the next page.

Where do guides fit in the buying process?

Before you enquire

Use a guide to decide the machine class, size and condition you want. A clear brief gets a more accurate offer.

While you compare offers

Use the inspection and load chart checklists to compare offers on the same basis, not only on price.

Before you ship

Use the export page to check documents, ports and local import rules, so the machine clears customs without delay.
